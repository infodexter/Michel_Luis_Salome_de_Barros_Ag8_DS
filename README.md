Pesquisa de Satisfação — TudoWeb
Descrição

Este projeto foi desenvolvido como atividade prática de programação em Python para a empresa fictícia TudoWeb.

O objetivo do programa é realizar uma pesquisa de opinião com os clientes da empresa, coletando informações sobre nome, idade e grau de satisfação com o atendimento prestado.

A pesquisa considera três opções de resposta:

1 — EXCELENTE
2 — BOM
3 — RUIM

Ao final da pesquisa, o programa apresenta a quantidade de entrevistados que avaliaram o atendimento como EXCELENTE e RUIM.
